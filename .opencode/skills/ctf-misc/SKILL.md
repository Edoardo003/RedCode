# CTF Misc

1. Start with `file`, hashes, strings, entropy, archive listing, and metadata.
2. Test common encodings and compression layers before using complex tools.
3. Keep every transformation in a small reproducible script under `solver/`.
4. Prefer a short verified chain over broad blind guessing.
5. Record the exact final extraction path in the write-up.
