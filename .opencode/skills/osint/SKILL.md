# OSINT Method

Start with a specific assessment question, not open-ended collection. Use public or analyst-supplied sources and record URL, retrieval time, search term, and relevance.

Corroborate infrastructure and identity claims before treating them as confirmed. Distinguish stale records, shared infrastructure, wildcard matches, similarly named people, and third-party services. Minimize personal data and do not contact subjects, bypass access controls, or obtain data from illicit sources.

Return only intelligence that changes scope review, asset priority, authentication testing, or remediation. Save source references and uncertainty; do not copy large source pages into the handoff.
