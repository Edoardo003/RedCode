# CTF OSINT

1. Start from the challenge-provided names, images, coordinates, domains, or timestamps.
2. Use only public sources and record every URL, capture time, and inference in `notes.md`.
3. Prefer direct primary sources over copied summaries.
4. Keep a clear distinction between observed facts and hypotheses.
5. Verify the candidate flag against the stated format or multiple independent sources.
